# AI-Based Intrusion Detection System

## Overview

This project implements an Intrusion Detection System (IDS) using Machine Learning to detect malicious network traffic and classify attacks.

## Objective

To analyze network traffic and identify potential cyber attacks using a Random Forest classifier trained on the NSL-KDD dataset.

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib
* Joblib

## Dataset

NSL-KDD Dataset

## Features

* Data preprocessing
* Attack classification
* Machine learning-based detection
* Confusion matrix generation
* Performance evaluation

## Model

Random Forest Classifier

## Results

* Dataset Records: 125,973
* Features: 43
* Accuracy: 99.80%
